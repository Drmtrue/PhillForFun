# Трансформация безрабочего

Квиз о Филе: 10 случайных вопросов из общего пула, 4 варианта ответа, общий рейтинг.
Любой игрок может добавить факт о Филе — ИИ (Claude) сам придумает по нему смешные вопросы и добавит их в игру.

## Как устроено

- **Сайт** (`index.html`, `style.css`, `app.js`) — GitHub Pages.
- **Встроенные вопросы** — `questions.js`.
- **Сервер** (`worker/`) — Cloudflare Worker: принимает факты, генерирует вопросы через Claude API, модерирует, хранит вопросы и рейтинг.
- **Админка** — `admin.html`: просмотр и удаление вопросов от игроков, журнал фактов.

Без сервера (`API_URL` в `config.js` пустой) сайт работает в локальном режиме: только встроенные вопросы, рейтинг в браузере.

## Запуск сервера (один раз)

1. Получи API-ключ на https://console.anthropic.com (Settings → API keys), пополни баланс.
2. Зарегистрируйся на https://dash.cloudflare.com.
3. Workers & Pages → Create → **Import a repository** → подключи GitHub → выбери `PhillForFun`.
   В настройках сборки укажи **Root directory: `worker`**. Deploy.
4. В созданном воркере: Settings → Variables and secrets → добавь секреты:
   - `ANTHROPIC_API_KEY` — ключ из шага 1;
   - `ADMIN_TOKEN` — любой длинный пароль для админки.
5. Скопируй адрес воркера (`https://phill-quiz-api.….workers.dev`) в `API_URL` в `config.js`.

После этого любой пуш в репозиторий сам обновляет и сайт, и сервер.

## Настройки сервера (`worker/wrangler.toml`)

- `MODEL` — модель Claude для генерации;
- `FACTS_PER_HOUR_PER_IP` — сколько фактов в час можно добавить с одного адреса (по умолчанию 20);
- `FACTS_PER_DAY_TOTAL` — общий дневной лимит, защищает баланс API (по умолчанию 100).

## Встроенные вопросы

`questions.js`, формат:

```js
{
  q: "Текст вопроса?",
  correct: "Правильный ответ",
  wrong: ["Неправильный 1", "Неправильный 2", "Неправильный 3"]
},
```
