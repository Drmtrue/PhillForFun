# Трансформация безрабочего

Квиз о Филе: 10 случайных вопросов из общего пула, 4 варианта ответа, общий рейтинг.

## Как добавить вопросы

Открой `questions.js` и добавь блок по образцу:

```js
{
  q: "Текст вопроса?",
  correct: "Правильный ответ",
  wrong: ["Неправильный 1", "Неправильный 2", "Неправильный 3"]
},
```

Ответы перемешиваются сами, правильный всегда пиши в `correct`.

## Файлы

- `index.html`, `style.css`, `app.js` — сам сайт
- `questions.js` — пул вопросов
- `config.js` — название, число вопросов за игру и настройки Firebase для общего рейтинга
- `firestore.rules` — правила базы рейтинга (вставляются в консоли Firebase)

Без Firebase рейтинг хранится только в браузере игрока.
